# 现稿反思与修订依据

现稿优点：生活入口清晰，Andy的技术背景一致，前后以椅子和餐桌呼应；不能为增加戏剧性破坏这些基础。

主要问题及证据：
1. 冲突过快闭合。第1章修水龙头时间一问就改成下午，第2章冰箱归属同场解决，第4章错饮品立即更换。每个场景单看可信，连续阅读却容易预知结局。修订保留这些事件，增加等待、被打断、顾虑与后续责任，而非强行把服务员写成反派。
2. 配角常承担教练职责。第4章Rui说“You said it”，第8章Maya连续追问CV贡献，第19章Rui说“Start with the people this time”。需要让他们的时间、工作和家庭安排真正影响互动，并让Andy回过头支持他们。
3. 重大的生活变化被时间跳跃压缩。第6章末明确最后工作日，下章直接到“My team closed a month ago”。可以通过具体生活选择和交接回忆呈现代价，而非只用预算概述。
4. 后半段情节载体重复。第14章更新任务、第16章准备短记录、第17章写事故记录、第18章发讨论稿、第21–22章改建议稿。保留真实工程沟通，但用不同人物的行动与不一致反应承接后果，减少清单像课堂小结一样结尾。
5. 情感后果容易被正确表达消解。第11章落选和Rui入职的复杂感受有基础，但很快转为下一份职位；第22章Daniel同意改进较顺畅。修订应允许友谊中的不自在、合理反驳、时间成本继续存在。
6. 客户工作细节多于人的声音。第23章有人接到两次电话，但主要经流程汇报。可以通过有限、可信的现场转述或通话，让学员如何安排交通/照顾家人的具体需要进入决策。

修订不以固定增字比例验收：新增场景应改变信息、选择、关系或后果。前六章保留易听懂的短句，复杂性先来自真实互动；后期增加保留意见、权衡、打断与澄清，不靠生僻词宣称C1。
