# 逐句中文验证

功能：点击正文英文句子，在跟读面板显示简体中文；主动切换上一句、下一句也显示中文。展开后随面板英文同步，连续播放不会自行展开已收起的中文。手动翻章收起中文。

数据：24章独立JSON按句子ID映射；AI根据章节上下文翻译，不在浏览器调用第三方翻译接口。运行时只按需读取当前章并缓存。

验证：
- 翻译控制器覆盖隐藏时不请求、章缓存、同章并发去重、旧请求不覆盖新句、隐藏后不重开、加载错误与重试。
- 原有24项播放器回归测试，验证持续播放、按章加载、循环、暂停与恢复。
- 逐章校验ID集合完整和译文非空；独立抽查语义并修正15-42的“下周五”日期表达。
- 浏览器实操：正文点击显示对应中文、下一句中英文同步、循环正常、收起不中断、手动翻章隐藏及再次按需查看。
- 手机390×844视口检查：中文面板、控制按钮、正文可见，无横向溢出。实体手机未直接操作。
